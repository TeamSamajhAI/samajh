SamajhAI 

An Indic-first, voice-enabled AI assistant that explains documents in simple language using Sovereign AI principles.

 🌟 Features
- Voice-based document explanation
- Indic language support
- Text, voice, and document input
- Simple and accessible design

 🛠️ Tech Stack
- Frontend: React
- Backend: Node.js
- AI: Groq + Sarvam
- OCR: Google Vision

👥 Team Roles
- AI Systems Engineer
- Frontend Engineer
- Backend Engineer
- DevOps & Product Engineer
